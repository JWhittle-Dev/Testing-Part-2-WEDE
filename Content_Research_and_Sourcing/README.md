# Content Research and Sourcing — Durban Youth Council

Per Part 1, section 3.1 of the brief, this folder gathers and organises the
content researched for the Durban Youth Council website ahead of the HTML
build. It follows the four sourcing categories set out in the brief.

## Folder guide
- `sources.md` — every source consulted, with URL and access date.
- `page-content/` — the organised, page-by-page written content used in the
  HTML build (original content, not copied verbatim from any source).
- `images/` — image sourcing record (all current images are original SVG illustrations).
- `documents/` — placeholder for any source documents (e.g. an annual
  report or constitution) obtained directly from the organisation, if DYC
  supplies one.
- `text/` — raw notes taken during research, before being written up into
  `page-content/`.

## 1. Organisation's website (starting point)
`durbanyouthcouncil.co.za` was checked directly. As of this research pass it
shows only a logo and the message "New Website Coming Soon" with a contact
email — there is no existing page content to draw from or migrate. This is
recorded as a finding in the proposal's "Current Website Analysis" section
rather than a content source.

## 2. Social media
No active, verifiable Durban Youth Council social media account was located
during this research.

## 3. Public domain and Creative Commons resources
See `assets-sourcing.md` for the specific free/ libraries selected for
fonts, icons and (once sourced) photography, with licence notes.

## 4. Original content
All page copy in `page-content/` was written specifically for this project
based on the verified facts in `sources.md` (e.g. DYC's founding year and
origin as a Junior Chamber International project). Programme names and
descriptions, mission/vision phrasing, not copied from any external source — this keeps the site's
copy fully within my own authorship, as required.
