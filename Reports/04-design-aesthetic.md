# 4. Design Aesthetic

## Concept
Warm, youthful and trustworthy. Dark charcoal and teal convey stability and seriousness; amber adds energy
and is reserved for calls to action so they stand out.

## Colour palette
| Name | Hex | Use |
|------|-----|-----|
| Charcoal | `#1b1b1e` | Header, footer, body text |
| Teal | `#1f6f78` | Page headers, links, icons |
| Teal dark | `#164f56` | Hero gradient |
| Amber | `#e8a33d` | Buttons and the "Get involved" strip |
| Amber dark | `#c8842a` | Button hover |
| Light grey | `#f4f4f4` | Alternating section backgrounds |
| White | `#ffffff` | Page background, cards |

Charcoal text on white and charcoal text on amber both give strong contrast; contrast should be re-checked
for any new colour pairing against WCAG 2.2 (W3C, 2023).

## Typography
- **Headings:** Poppins 600/700 — friendly, geometric and highly legible (Google Fonts, n.d.a).
- **Body:** Inter 400/500/600 — designed for screen reading (Google Fonts, n.d.b).
- Fallbacks: Arial, Helvetica, sans-serif.
- Scale: `clamp()` is used for headings so they resize smoothly between phone and desktop.

## Imagery
Original flat-style SVG illustrations in the same palette. Each image has alt text. Real, licensed photographs
of DYC volunteers (with consent) should replace or join them when available.

## Layout principles
Single central container (max 1100px), generous spacing, card grids, alternating section backgrounds,
mobile-first thinking.
