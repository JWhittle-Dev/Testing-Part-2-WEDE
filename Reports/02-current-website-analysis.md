# 2. Current Website Analysis

*(Previously covered only in the summary/background; now a dedicated section.)*

## What exists today
`durbanyouthcouncil.co.za` was checked on 1 September 2026. It shows a logo, the message
"New Website Coming Soon" and a contact email. There is no navigation, no content and no way to enquire.

## Strengths
- The organisation already owns a recognisable domain name.
- A working contact email exists (`info@durbanyouthcouncil.co.za`).
- A clean slate: nothing needs to be migrated, so the structure can be designed properly.

## Weaknesses
| Issue | Effect on visitors |
|-------|--------------------|
| No information about the organisation | Visitors cannot tell what DYC does or whether it is active. |
| No enquiry route | Interested volunteers and sponsors have nowhere to go. |
| No programme information | Schools and charities cannot assess a partnership. |
| No mobile-friendly design | Most South African web traffic is on phones, so a poor mobile experience loses visitors. |
| No social links | No way to follow DYC's activity. |

## Social media presence
No verified, active DYC social media account was found (see `Content_Research_and_Sourcing/README.md`).
Facebook and Instagram links in the footer are placeholders until accounts are confirmed.

## Opportunities
- Present the 60-year history as a credibility signal.
- Use a single clear call to action ("Become a volunteer") across all pages.
- Show both locations to help local volunteers find DYC.

## Conclusion
Because the current site is only a placeholder, the project is a full build rather than a redesign.
The priorities are information, enquiry, contact and mobile readiness.
